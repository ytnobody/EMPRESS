- 1. The configured base_branch must exist locally before worktrees can be created. In a freshly-cloned repo where the default branch is `master` but empress.toml sets base_branch=main, empress_create_worktree fails with `base branch "main" not found locally`. Fix by aligning branches (create `main` at HEAD) BEFORE spawning engineers, and verify with empress_list_branches / git branch. Also: scripts/selfcheck.js sits in high_paths, so ANY selfcheck edit returns deterministic HIGH; review the patch — if the selfcheck change is purely additive test-verification it is effectively LOW and warrants leaving a recommendation for a human rather than force-landing.
